# My Expense Tracker (Mobile App)

A beautiful personal expense tracker that you can **install on your phone**.

## Features
- Add your **profile picture**
- **Password lock** (optional)
- Add / delete expenses
- Categories with icons
- Total spent + This month summary
- Filter by category
- Works **offline**
- Data stays only on your phone
- Looks like a real mobile app

---

## How to Install on your Phone

### For Android:
1. Open the `index.html` file in **Chrome** browser
2. Tap the **three dots** menu (⋮)
3. Tap **"Add to Home screen"** or **"Install app"**
4. The app will appear on your home screen like a normal app

### For iPhone:
1. Open the `index.html` file in **Safari** browser
2. Tap the **Share** button (square with arrow)
3. Scroll and tap **"Add to Home Screen"**
4. Tap **Add**
